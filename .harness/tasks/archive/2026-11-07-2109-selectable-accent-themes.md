# 用户可选主题配色
状态=已完成
更新时间=2026-11-08 23:21

## 目标与背景

在保持浅色、灰白分层的界面基调下，提供墨绿、海蓝、鸢尾紫、玫瑰莓、琥珀棕、石墨六种可持久化的主题配色。墨绿仍为默认选项。

## 范围

- DataStore 保存主题选择，应用根主题响应偏好变化。
- 偏好设置增加当前色样入口，以及一行优先、窄屏两行的圆形色块选择器。
- 清理 Compose 页面中绕过主题的固定绿色，保留错误、成功和中性色语义。
- 启动画面、Logo 和启动图标维持品牌资源，不随应用内强调色变化。

## 验收标准

- 新旧用户默认墨绿；切换任一主题即时影响主页面、二级设置、应用锁与 AI 界面，重启后保留选择。
- 页面不残留固定绿色，文字及交互状态有足够对比；错误状态保持错误色。
- Windows Gradle 单元测试和调试包构建通过；按用户本次要求不运行模拟器测试，OPPO / ColorOS 真机视觉与操作验收仍须完成。

## 实施步骤

1. 建立五款主题色板与 DataStore 偏好。
2. 接通应用根主题与偏好页选择器，清理固定绿色。
3. 添加单元测试、运行 Windows 构建与测试，更新规格并等待真机验收。
