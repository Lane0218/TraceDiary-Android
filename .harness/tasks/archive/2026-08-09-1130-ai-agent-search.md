# AI 语义搜索与云端 Agent
状态=已完成
更新时间=2026-08-11 18:51

## 目标与背景

- 在“回顾”中新增独立 AI 搜索页，让用户无需记住原始关键词即可查询日记，例如过去一年去过的城市、评价较好的餐馆或洗牙日期。
- 采用端侧加密语义索引与用户自带 Key 的云端只读 Agent；本地不运行生成式 Agent，云端只能通过受限工具读取证据。
- 保证所有仍存在或已恢复的用户内容只依赖唯一应用密码和公开固定协议参数即可解密，禁止引入卸载后丢失的安装级恢复材料。

## 范围

- 回顾页新增“AI搜索”子页，顺序为“AI搜索 / 搜索 / 年度总结”，默认进入 AI 搜索，并使用无点击反馈的轻量文字 Tab 与底部指示线。
- 四个一级页面删除重复大标题；今天页将月份跳转、返回当天和清空当日内容分别归入月份文字、底部导航重复点击和编辑卡片菜单。
- 固定使用 INT8 ONNX 版 `BAAI/bge-small-zh-v1.5` 在端侧生成向量，仅从 ModelScope 镜像仓库的固定 revision 下载，逐文件校验后原子启用。
- 新增复用主数据库 passphrase 的独立 SQLCipher AI 索引数据库，覆盖全量首建、增量更新、删除、导入、同步、改密和损坏重建。
- 支持用户配置 HTTPS OpenAI Chat Completions 兼容服务，提供 DeepSeek 预设，实现临时多轮问答、无需额外授权的大范围只读工具调用和本地证据验证。
- “AI搜索设置”页按“AI搜索 / 端侧模型与加密索引 / 云端大模型”排列，复用同步设置的开关与行内输入样式；索引就绪时“重建索引 / 清理索引”左右并排。
- 设置体系的选择、确认、进度和结果对话框统一使用 14 dp 圆角的共享视觉外壳，并保留不同场景的交互语义。
- AI 搜索使用统一圆角、边框、内边距和无阴影的双侧问答气泡及单层底部输入框，仅通过颜色区分；资料默认折叠为气泡内去重计数摘要，摘要无点击反馈，通过无 Tooltip 高亮的底部资料面板查看和跳转。
- 临时会话不持久化；“开始新会话”二次确认后同时清除界面与 Agent 上下文，应用锁定或进程结束时自动清除。
- AI 可读取日记、年度总结、本地统计和普通偏好；永久排除密码、密钥、Token、密文和底层同步配置。
- 不保存问题、回答或结构化事实缓存；普通设置、云 AK/SK、AI API Key 和模型文件不纳入卸载恢复。
- 风险等级：高；主要风险为内容恢复性、隐私外发、模型兼容性、端侧性能、索引一致性、提示词注入和答案幻觉。

## 验收标准

- 正确应用密码可在不依赖旧 Keystore、DataStore、设备 ID 或安装 ID 的新安装环境中打开恢复的主数据库和 AI 索引；错误密码不能打开。
- AI 索引丢失、损坏、改密或版本不匹配时可安全重建，不删除或破坏主日记数据库。
- 索引完整前禁止提问；日记和年度总结发生增删改、导入或同步后，索引按正文哈希正确增量更新。
- Agent 只能调用规定的只读工具，任何请求和工具结果都不包含密码、API Key、云 AK/SK、密文或底层同步配置。
- “去了/计划去/没去成”“好吃/不好吃”“预约/取消/实际洗牙”等问题能基于测试数据给出证据受限回答；伪造日期或非原文证据不能通过本地验证。
- 临时多轮会话可连续追问、切换回顾子页时保留，并在开始新会话、应用锁定或进程结束后消失；应用锁定立即取消索引和 Agent 工作。
- 四个一级页面无重复大标题，回顾文字 Tab、今天页操作迁移、双气泡、依据面板和单层输入框在常见手机宽度下无裁切、重叠或不可达操作。
- 大范围分析无需额外授权，但仍受应用解锁、只读工具、日期范围、正文量、调用次数和执行时间限制；关键词搜索在模型缺失、断网或 Agent 错误时仍可正常使用。
- OPPO Find X9 Pro 16 GB 达到：模型下载资产不超过 100 MB、冷加载不超过 3 秒、查询向量 P95 不超过 1 秒、千篇 500 字日记在 5 分钟内完成索引、额外峰值内存不超过 512 MB。
- Windows 环境 `gradlew.bat test`、`gradlew.bat assembleDebug`、相关 `connectedAndroidTest` 通过，并完成 OPPO / ColorOS 真机的模型、恢复、锁定、网络、性能和证据跳转验收。
